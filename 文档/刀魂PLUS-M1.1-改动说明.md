## P0-1 · LOCAL VS 第二位玩家选角空屏

**根因**
M1 的 P2 选角是在原 `drawSelect` 外面反复包 wrapper（函数覆写链）实现的。链条中某层在 `char2` 阶段直接 `return`，后续层画不出网格，导致 P2 回合黑屏且无法返回。

**修复方式**
新增 `js/select2.js` 作为**唯一**的选角/模式模块，整体收敛（不再叠 wrapper）：

- `char → char2(仅 LOCAL VS) → stage → diff(仅 VS CPU) → vs` 单一状态机；
- `char2` 为正式阶段：六人网格重绘、P2 独立光标（青色，方向键驱动，`cursor2`）、P1 已锁定角标（1P 金标）、`P2 SELECT` 标头与小键盘键位提示；
- P2 确认 = 小键盘1 / `[`（备用）/ J（帮选）；返回 = 小键盘2 / `]` / K，回到 P1 重选不卡死；
- 允许镜像内战（P2 可选与 P1 同角色）。

**验证**
真实浏览器截图 `08-选人-P2网格-LOCALVS.png`；无头断言 char2 阶段 drawImage≥6、含 "P2 SELECT" 与 "P1 ✓" 文案；小键盘确认后进入 stage 阶段。

## P0-2 · 六人尺寸 / 锚点 / 碰撞盒统一

**根因**
新三人（悟空/后羿/安琪拉）用 128px 帧 × scale 2.9 直接放大，屏显 ~240px，比原三人（145-150px）大 60%；碰撞盒也按旧比例写，导致「巨人打小人」且判定不对位。

**修复方式**
- 烘焙器 v2（`_build/bake_roster2.py`）重烘 192px 帧（FEET_Y=150，CX=70），挥击不再被 128 帧裁切；
- `roster.js`：`fw:192`、scale 降到 1.78 / 1.85 / 1.90，脚底锚点对齐，屏显统一 146-150px（六人 spread 3.3%，门槛 <10%）；
- 全部招式 hitBox 按 ~0.64 系数手工重写死值（拒绝运行时乘系数——引擎按世界坐标直读 box，运行时缩放会伤原三人）；
- `fighter.js`：`bodyBox` 改每角色可配，蹲姿身高 148 → 96（<75% 门槛）。

**验证**
无头断言六人屏显高度与 spread、蹲盒比例；真实对战截图 `10`（wukong vs hayato 同框）、`17`（mack vs ayame）、`18`（houyi vs kenji）目视等高。

## P1 · 主菜单四项排版

**根因**：M1 硬塞第四项（LOCAL VS）时沿用三项坐标，选项与底部提示重叠。
**修复**：`ui.js` 菜单纵向坐标重排（by=354+i*40），提示行下移至 552；W/S 循环导航 %4。
**验证**：截图 `01-标题-四菜单.png`，四项+提示零重叠；S×4 循环回位断言。

## P1 · 模式状态单一可信源（互不污染）

**根因**：LOCAL VS 用平行标志位驱动，退出后残留，再进 VS CPU 时对手失去 AI 或 HUD 标签错乱。
**修复**：复用引擎原生 `G.p2IsAI` 作唯一可信源（select2 的 `startMatch` 包装统一设置；`updateTitle` 回标题即复位 true）；HUD 标签（P1/P2/CPU/DUMMY）只从它 + `G.mode` 派生，只画一处。
**验证**：真实浏览器完整走 LOCAL VS → 标题 → VS CPU，断言 `p2IsAI===true` 且 `G.ai[1].plan` 存在（真 AI 控制器）；截图 `16-模式切换-CPU回归.png`（CPU 标签）、`10`（P2 标签）、`13`（DUMMY 标签）。

## P1 · VS 页双重绘制

**根因**：M1 在原 sprite 预览之上又叠画立绘，同一角色出现两个重影主体。
**修复**：`_drawVs` 重写为单主体构图——立绘为主体（sprite 仅在立绘缺失时 fallback），左右滑入 + 中央 VS 徽章 + 底部舞台条；LOCAL VS 显示 P1/P2 徽标，VS CPU 显示 `CPU·难度`。
**验证**：截图 `05-VS页-CPU.png`、`09-VS页-LOCALVS.png`，单主体无叠影。

## P1 · 后三名关键视觉（本轮真实浏览器验收中发现并修复）

**根因**：`bake_bust` 把整只 3.2 倍小人画进 320×344 画布——立绘区/HUD 头像/VS 页/结算页出现「空框飘小人」，与 mack/kenji 手绘胸像并排即穿帮。首轮 Puppeteer 截图（02/05/09 旧版）确认了该问题。
**修复**：重写胸像合成器——真正的肩上构图：头部 ~120px 居中、角色专属肩甲/披风撑满下缘（悟空金甲红披风、后羿银肩胸甲+箭袋束带、安琪拉泡泡袖+束胸、绫的忍装+银十字束带+围巾），HUD 头像同步改为面部特写裁切；重烘 8 张 portraits。
**验证**：第二轮截图 `02/05/09/11/12/19` 全部目视复核，胸像构图与手绘版同框不穿帮。
