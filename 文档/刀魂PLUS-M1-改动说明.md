## P0 · 单文件资源修复（本轮最高优先级，已修复并验证）

**问题确认属实**：`_loadImg()` 实际请求 `/assets/ui-lab/*.webp`（带头部斜杠 + webp 替换），而旧内嵌表键名是 `assets/ui-lab/*.png`——26 个 UI 请求全部失配，16.8MB 高质量 UI 原画被打包却从未生效，全部静默走程序化 fallback。

修复内容：

1. **改嵌 webp**：镜像了线上全部 26 张无损 webp（11.2MB，作者本意的首屏优化版），ui-lab 的 png 原稿保留在磁盘但不再重复内嵌
2. **实现 `resolveEmbeddedAsset()`**（按 M1 Prompt 规格）：剥离 origin/头部斜杠/query/hash，`/assets/` 截取，webp↔png 双向回退
3. **断网兜底**：未命中内嵌表的 `assets/` 请求直接拦截并 console.warn，绝不向外部发请求
4. **多文件版加固**：`_loadImg` 增加 webp→png 重试链（HTTP 环境双保险）

资源审计：删除 4 个仅调试参数可达的变体（title-kanban/gunsen/torii、announce-brush-slim）；26 个 ui-lab png 改为不内嵌。**体积 26.6MB → 19.9MB**（目标区间 15-22MB ✓）。
