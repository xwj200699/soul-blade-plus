## 3 · L3 实测视频产物校验

| 校验项 | 结果 |
| --- | --- |
| 容器头 | `ftyp isom`（标准 mp4）✓ |
| 视频轨 | H.264/avc1（Baseline）✓（canvas.captureStream 60fps，6 Mbps） |
| 音频轨 | Opus ×1 ✓（AudioSys.recorderStream master 旁路，含 BGM/音效） |
| 体积/时长 | 54 MB / 约 3.5 分钟，录制脚本全段落零 wait 超时 |

> 编解码选型经真实探针验证：Chromium 无 AAC 编码器（`avc1+mp4a` 组合产空壳）、
> 裸 `video/mp4` 自选会落到 VP9（兼容差）、H.264 High profile 编码停摆，
> 最终采用 `avc1.42E01E(Baseline)+opus`（唯一健康且最大兼容组合）。

内容段落（慢节奏编排：画面停留/对白读秒/出招间隔加长）：标题菜单 → 鼠标进
闯关（悟空 EASY：开幕剧情+第一波双敌混战）→ VS CPU 悟空 @青铜神殿（金箍棒
必杀/超杀）→ 训练场超杀秀（安琪拉激光、貂蝉花舞·乱影）→ 回标题。全程
puppeteer 真实键鼠驱动，无剪辑。
