# GitHub 同步流程（常驻规则）

本项目已上线**公开**仓库 `https://github.com/evans777max/soul-blade-plus`（`origin/main`，账号 evans777max，gh CLI 已登录），并启用 GitHub Pages 在线试玩。

**公开仓库红线**：任何第三方内容（参考视频、他人素材、内网信息、个人信息）一律不得入仓；`video.mp4` 等参考素材已列入 `.gitignore`。

## 规则

1. **每当一轮实质工作完成并通过验收**（里程碑交付、bug 修复、新功能、文档/资产更新），在收尾时执行同步：
   ```powershell
   git add -A
   git commit -m "<前缀>: 一句话中文说明"
   git push
   ```
   前缀约定：`M1.x:`（血刃主线）/ `NewFight-M2:`（Q版分支）/ `文档:` / `修复:`。
2. 纯讨论、无文件变化的轮次不提交。
3. 提交前留意：>100MB 单文件不入仓（GitHub 硬限制）；临时日志/抽帧已由 `.gitignore` 排除，勿手动加回。
4. 推送后用 `git ls-remote --heads origin` 或 `git status -sb`（看 ahead/behind）确认到位——此前发生过 `gh repo create --push` 建仓成功但推送中断的情况。
5. 本机终端读 git 输出常见"假 ^C"，重定向到文件再读即可。
